Drive Folder Copier

Copy any Google Drive folder or file — including all subfolders — directly into your own My Drive, using Google Drive's own picker.

What it does

  • Copies any folder or file, including all subfolders and files
  • Select what to copy using Google Drive's own picker interface — no manual links
  • Choose any folder as the destination
  • Keep or remove the copy's sharing permissions

Common uses

  • Copy a folder someone shared with you
  • Create backups of folders
  • Reorganize your folder structure
  • Retain access to files from employees who are leaving

Privacy

Drive Folder Copier does not collect, store, or transmit your Drive files or folder data to any server. All copying happens directly between your browser and your own Google account. See the full Privacy Policy.
